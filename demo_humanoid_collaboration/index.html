Humanoid Collaboration for Cooperative Manipulation

NYU AIR Lab

New York University, NYU Abu Dhabi

Overview

This project explores collaborative task execution using multiple humanoid robots working in unison. The system is designed for dynamic role allocation, shared decision-making, and synchronized control during joint manipulation of large or complex objects.

  • Collaborative Task Planning: Robots communicate and coordinate to achieve shared goals.
  • Multi-Agent Synchronization: Precise timing and motion synchronization for safe and efficient collaboration.
  • Shared Environment Awareness: Each humanoid adapts to the movements and force feedback of its partners.
