Humanoid Robot Object Navigation

NYU AIR Lab

New York University, NYU Abu Dhabi

Overview

This project aims to empower humanoid robots with the ability to navigate toward specific objects in real-world indoor environments. By leveraging multi-modal sensing and goal-directed reasoning, humanoids can perceive, plan, and act to reach and interact with objects in cluttered, dynamic scenes.

  • Object-Goal Navigation: Search and reach user-specified targets via vision and language guidance.
  • Humanoid Mobility: Realistic walking, balancing, and locomotion in complex layouts.
  • Scene Understanding: Combines egocentric visual input with spatial reasoning for reliable task execution.
