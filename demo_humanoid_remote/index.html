Humanoid Remote Teleoperation

NYU AIR Lab

New York University, NYU Abu Dhabi

Overview

This project explores real-time remote teleoperation of humanoid robots using multimodal communication channels, including vision, speech, and haptic feedback. The goal is to create intuitive and high-bandwidth interfaces that enable operators to guide humanoid agents through complex manipulation and navigation tasks in distant or hazardous environments.

Key Features

  • Visual-Tactile Feedback: First-person video, tactile alerts, and feedback-driven adjustments.
  • Shared Autonomy: Mixes autonomy and operator control for efficient task execution.
  • Network-Aware Execution: Adaptive latency handling for remote or variable bandwidth.
